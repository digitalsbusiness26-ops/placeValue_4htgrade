Detective Field Guide

Step 1: Read the Clue. Look at which place values are mentioned.

Step 2: Build with Blocks (Optional). Use the + button under each column to place blocks.

Step 3: Count and Write Digits. Type how many blocks are in each column into the box below it.

Thousands (Cube)
Value = 1,000
Example: 3 cubes = 3,000
Hundreds (Flat)
Value = 100
Example: 2 flats = 200
Tens (Rod)
Value = 10
Example: 5 rods = 50
Ones (Unit)
Value = 1
Example: 4 units = 4

🚨 The Zero Rule: If a zero is in the middle of two digits (like 305) or is the last digit (like 250), you MUST type a 0 in that box! Front leading zeros are optional.
